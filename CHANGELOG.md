# Изменения

## 0.1.0

Первый публичный выпуск CLI BPMN Forge: [исходники](https://github.com/DatKorso/bpmnforge) и [готовый пакет](https://github.com/DatKorso/bpmnforge/releases/tag/v0.1.0) доступны на GitHub. В реестре npm этот выпуск не публиковался.

- Название продукта — BPMN Forge; CLI и npm-пакет — `bpmnforge`.
- Единый JSON версии 1 → автономный интерактивный HTML и BPMN 2.0 с общей DI-геометрией.
- Этапы, описания, документы, клавиатура, панорама, масштаб, сетка и переходы к общим процессам.
- Задачи, XOR/AND, возвраты, несколько участников, локальные вызовы, таймеры и одноуровневые событийные подпроцессы в поддерживаемом профиле.
- Диагностика `RESERVED_ID` для свойств Object.prototype; совместимое исправление `fast-uri` до 3.1.9.
- MIT для собственного кода; полные уведомления библиотек браузерного bundle в HTML и пакете, с сохранением логотипа bpmn.io.
- Полная локальная проверка: unit, browser и реальная установка `.tgz`; только синтетические fixtures.
- Руководства пользователя и LLM. Версия пакета `0.1.0`, публичный тег `v0.1.0`.

Ограничения: Node.js 24+, локальная приёмка на Node 24/26 и macOS; Windows пока не проверена. Сложная геометрия может потребовать подсказок. Импорт BPMN, новые бизнес-примеры, GitHub CI и автоматическая публикация отложены.
